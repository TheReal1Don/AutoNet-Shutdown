Description:
AutoNet-Shutdown is a C# console utility that monitors your network download speed in real-time. It is designed to automatically shut down your computer once the download speed drops below a user-defined threshold for a specific duration. This is perfect for users who want to leave large downloads running overnight without keeping the PC powered on unnecessarily.

Key Features:

Real-time Monitoring: Tracks incoming network traffic across all active interfaces.

Customizable Thresholds: Users can define the minimum download speed (KB/s) and the wait time (seconds) before shutdown.

Simple & Lightweight: Minimal resource usage, perfect for running in the background.

Automatic Shutdown: Uses native Windows shutdown commands to safely power off the machine.

Usage:

Run the application with Administrator privileges (if required).

Input your desired download speed threshold (KB/s).

Input the duration of inactivity (in seconds) required to trigger the shutdown.

The tool will monitor your connection and initiate the shutdown once the conditions are met.
