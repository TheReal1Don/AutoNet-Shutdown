# AutoNet-Shutdown

### English

**Description:**
AutoNet-Shutdown is a lightweight C# console utility that monitors your network download speed in real-time. It is designed to automatically shut down your computer once the download speed drops below a user-defined threshold for a specified duration, helping to save energy and system resources after large file downloads or tasks complete.

**Key Features:**

* **Real-time Monitoring:** Tracks incoming network traffic across all active network interfaces.
* **Customizable Thresholds:** Users can define the minimum download speed (KB/s) and the required duration of inactivity (seconds) before shutdown.
* **Lightweight:** Minimal resource usage, designed to run quietly in the background.
* **Safe Shutdown:** Uses native Windows commands to initiate a controlled system shutdown.
